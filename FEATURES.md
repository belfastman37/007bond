# AppForge - Feature Summary

## What is AppForge?

AppForge is a complete Android IDE that runs on your Android device, enabling you to create Android applications without needing a PC. It's perfect for:

- Learning Android development on-the-go
- Quick prototyping of app ideas
- Making small edits to projects
- Coding when you don't have access to a computer
- Students learning mobile development

## Core Features ✨

### 📝 Professional Code Editor
- **Syntax Highlighting**: Java code with color-coded syntax
- **Line Numbers**: Easy code navigation
- **Monospace Font**: Optimized for code readability
- **Auto-indentation**: Proper code formatting
- **Undo/Redo**: Mistake-proof editing
- **Dark Theme**: Comfortable for long coding sessions
- **Multiple File Tabs**: Work on several files simultaneously

### 🗂️ Project Management
- **Create Projects**: Set up new Android projects instantly
- **Project Templates**: Start with working code
- **Recent Projects**: Quick access to your work
- **Project List**: View and manage all projects
- **Auto-save**: Never lose your changes
- **Package Naming**: Proper Android package structure

### 📁 File System
- **File Browser**: Navigate your project structure
- **Create Files**: Add new Java files
- **Open Files**: Quick access to any project file
- **Save Files**: Persistent storage
- **Close Files**: Manage open tabs
- **Full Structure**: Complete Android project hierarchy

### 🏗️ Project Structure
Every project includes:
- MainActivity.java (working Java activity)
- activity_main.xml (UI layout)
- strings.xml (string resources)
- AndroidManifest.xml (app configuration)
- build.gradle (build configuration)

### 🎨 User Interface
- **Material Design**: Modern, clean interface
- **Touch-Optimized**: Easy mobile interaction
- **Responsive Layout**: Works on all screen sizes
- **Intuitive Navigation**: Clear, simple workflows
- **FAB Menus**: Quick access to actions
- **Card-based Lists**: Beautiful project display

### 🔧 Build System (Interface)
- **Build Button**: Demonstrates build workflow
- **Run Button**: Shows run process
- **Progress Feedback**: Visual status indicators
- **Error Handling**: Clear error messages

## Technical Specifications 🔧

### Platform Support
- **Minimum SDK**: Android 7.0 (API 24)
- **Target SDK**: Android 14 (API 34)
- **Architecture**: Single module Android app
- **Language**: Kotlin (IDE), Java (generated projects)

### Dependencies
- **Sora Editor**: Advanced code editor
- **Material Components**: UI framework
- **AndroidX**: Modern Android libraries
- **Commons IO**: File operations
- **Gson**: JSON handling

### Storage
- **Location**: App-specific external storage
- **Format**: Structured Android projects
- **Persistence**: JSON project index
- **Size**: Minimal storage footprint

## Limitations 🚧

### Current Limitations
1. **No Full Compilation**: Requires Android SDK for APK building
2. **Java Only**: Generated projects use Java (not Kotlin)
3. **Basic Templates**: Limited to simple app structure
4. **No Visual Designer**: XML editing only
5. **Limited Debugging**: No integrated debugger

### Workarounds
- Transfer to PC for compilation
- Use cloud build services
- Learn Android SDK on device (advanced)
- Focus on code logic and structure
